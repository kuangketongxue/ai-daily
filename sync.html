同步设置

把收藏存进你自己的 GitHub 私有仓，电脑重置后也能取回。令牌只在你这台浏览器里，本站代码与仓库不含任何密钥。

当前状态

打开收藏夹

第一步 · 生成一把只管这一个仓库的令牌

GitHub 官方限制：访问令牌无法通过接口或命令行创建，只能你本人在网页生成。下面的链接已经预填好仓库与权限，点开确认即可。

  1. 点这个按钮：打开 GitHub 令牌生成页 ↗
  2. 确认 Repository access 只选了 kuangketongxue，Contents 权限是 Read and write。
  3. 起个名字、选有效期，点 Generate token，复制生成的那串字符。
  4. 粘到下面的输入框，点「保存到本机」。

不要把你命令行里已登录的那把令牌填进来 —— 它权限覆盖整个账号（含删库、组织管理），放进浏览器等于把账号交出去。这里只需要一把只管单个仓库的细粒度令牌。

第二步 · 粘贴令牌

保存后会自动连一次私有仓并把云端收藏取回。令牌不会出现在页面、日志、代码或任何提交里。

第三步 · 电脑重置后怎么恢复

  1. 重新打开本站（或重新部署），进「同步设置」。
  2. 令牌若没存进密码管理器，就在 GitHub 重新生成一把，粘贴保存。
  3. 点「从私有仓取回」，收藏全部回来。

收藏数据存在 kuangketongxue/kuangketongxue 的 data/daily-favorites.json，每次改动都是一次 Git 提交，误删可以回滚。

万星日报与本站同域名，令牌填一次，两个站都能用；两边收藏写在同一个文件里、按站分栏。

不联网也能搬 · 短码导出 / 导入

安全边界

  • 令牌只写进浏览器 localStorage，不下发到任何第三方，只用于向 api.github.com 发请求。
  • 断网时收藏改动会排队，联网后自动补传；云端冲突按「未同步操作重放」合并，不会把已取消的收藏复活。
  • 本站是公开静态页，其他访客打开只会看到空收藏夹，看不到你的令牌。
  • 在公用电脑用完记得点「清除本机令牌」；令牌也能随时在 GitHub 设置里吊销。
